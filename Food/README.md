This is a **beginner-friendly C++ program** that collects your favorite foods and displays them.  

The main philosophy here is **learning by reading heavily commented code**—if you can’t understand it after reading the comments, the code hasn’t explained itself properly!  

---

## Features

- Collects up to 10 favorite foods from the user
- Allows the user to stop early by typing `'q'`
- Displays only the foods that were entered
- Heavily commented so beginners can understand every step

---

## How to Run

1. **Clone or download** this repository.
2. Open the file in a C++ IDE (like Code::Blocks, Visual Studio, or VSCode with C++ extensions).
3. Compile the program:
   ```bash
   g++ -o main main.cpp
Run the program:

./main   # Linux/Mac
main.exe # Windows
